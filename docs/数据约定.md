# 盲审材料隔离数据约定

原件片段采用 Unicode 码点坐标，区间左闭右开；原文与遮盖位置的版本号一起保存。

data/example.json 中的记录均为虚构业务样例。字段名称与字段类型由 contracts 中的数据结构描述。原始记录按来源提供的顺序读取，字段值不在读取时改写。

## 版本与副本

- 原件每次变更（正文补充或遮盖策略更新）产生递增的 revision，text、spans、attachments 随版本号整体保存，历史版本仍可读取。
- 去标识副本记录 document_id 与 revision，内容在生成时按该版本区间一次性遮盖；重叠区间先合并，边界向外对齐字素簇（ZWJ 序列、旗帜、肤色修饰符、组合字符等不切开）。
- 副本状态机：draft → signed → claimed；draft 或 signed 状态的副本在原件出现新版本时转为 invalidated，已 claimed 的副本不受影响。
- 复核签名是对 copy_id、document_id、revision、内容摘要与签名者角色的 HMAC-SHA256，交付前验真。

## 隔离边界

- 回访方式（contact.channel / contact.value）只进 contacts 保险库，以随机 submitter_ref 为键，仅接收窗口角色可读。
- 下载令牌为一次性随机串，访问记录只含时间、角色、动作；两者均不含联系方式。
- 审计 detail 字段只写编号、版本号等白名单内容，禁止写入联系方式。
